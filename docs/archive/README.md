# Portfolio archive

This folder preserves material from earlier iterations of the portfolio without
including it in the production application bundle.

- `assets/about/` contains superseded biography and music-widget artwork.
- `assets/music/` contains alternate or unused audio-related media.
- `assets/projects/` contains project images that are no longer published.
- `writing/` contains drafts or locally retired copies of published writing.
- `legacy-home/` preserves the component tree from the superseded portfolio home.

Move an item back into `src/` when it should be bundled and imported by the app,
or into `public/` when it needs a stable direct URL.
